Herbal Assistant
Sistema de Monitoramento de Cultivo e Guia de Ervas Medicinais
Descrição
O Herbal Assistant é uma aplicação client-side desenvolvida para o gerenciamento de ciclos de cultivo doméstico e consulta de propriedades fitoterápicas. A ferramenta combina uma biblioteca técnica de espécies com um sistema de rastreamento de regas e fases de desenvolvimento vegetal.
Funcionalidades Core
Biblioteca Botânica: Base de dados integrada com informações sobre solo, iluminação, ciclo de vida e protocolos de preparo (chás, infusões e extrações).
Gestão de Cultivos: Monitoramento individualizado por planta, permitindo a definição de apelidos, datas de início e intervalos de rega customizados.
Algoritmo de Rega: Cálculo dinâmico de periodicidade baseado na data de germinação/plantio, fornecendo lembretes em tempo real.
Calculadora de Ciclos: Estimativa de fase fenológica (Germinação, Vegetativo, Adulta, Floração) com base no tempo de vida da cultura.
Portabilidade de Dados: Sistema de persistência em LocalStorage com módulos de exportação e importação de bases de dados em JSON.
Especificações Técnicas
Interface: CSS moderno com suporte a variáveis customizadas (Dark Theme nativo).
Engine: JavaScript Vanilla focado em manipulação de objetos e arrays.
Arquitetura: Aplicação de página única (SPA) funcional em modo offline.
Privacidade: Processamento e armazenamento de dados executado exclusivamente no dispositivo do usuário.
Configuração
A aplicação foi projetada para ser leve e portável.
Download do arquivo index.html.
Execução em qualquer navegador compatível com ES6.
(Opcional) Instalação via PWA para acesso direto na tela inicial.
